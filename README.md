# Generative Models Directed Reading Program

This repository contains materials from a Statistics Directed Reading Program focused on modern generative modeling methods.

The program involved reading and discussing research literature to understand both the mathematical foundations and modeling intuition behind several approaches in generative modeling.

## Topics Covered

The reading program explored topics including:

- Flow Matching
- Score Matching
- Diffusion Models
- Model Distillation

The focus was on understanding how these methods are formulated, why they were developed, and how they relate to modern generative modeling.

## Final Presentation

The final technical showcase focused on diffusion models and model distillation.

The presentation introduces the basic diffusion process, its formulation using stochastic differential equations, the forward noising and reverse generation processes, and the computational challenges associated with iterative denoising. It then discusses model distillation as an approach for reducing inference cost.
